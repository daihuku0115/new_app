■サービス概要
パソコンのデバイス関連をまとめているサイト

■ このサービスへの思い・作りたい理由
最近Ｅスポーツが盛んになってきていてマウス、キーボードといった製品も多種多様になってきています
ただ高額な商品である点、オンライン販売専門の品がある点により、自分が本当に必要としているものを見つける事が
だいぶ難しくなってきました。なのでより自分に合った製品を見つけることのできるサイトを作りたいと思いました。
■ ユーザー層について
ゲームをメインにしている世代、社会人が製品を決めやすいサイトを目標としているので
１８ー３０歳をターゲットにします。
■サービスの利用イメージ
ユーザーが自分に合った製品を発見、購入できるサイトを目標とします。
■ ユーザーの獲得について
想定したユーザー層に対してそれぞれどのようにサービスを届けるのか現状考えていることがあれば教えてください。
・販売サイトに飛べるようなサービス
・実際のサイズをウェブサイト上に原寸大で表示する
・用途、金額によっておすすめ商品を表示する。

■ サービスの差別化ポイント・推しポイント
自分の手の大きさ、用途によって探せるサイトは限りなくない。＋あっても海外のものなので日本語でより分かりやすいものを作ろうと思います。

・製品の検索(自分の手のサイズ、ゲームジャンル、価格帯、人気度を入力できる欄を作成し、検索を行う。)
